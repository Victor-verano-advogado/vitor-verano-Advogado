# ⚖️Victor Verano — Advocacia & Consultoria Jurídica

Website institucional e plataforma de atendimento jurídico 100% online desenvolvido para o escritório do **Dr. Victor Verano**. O projeto conta com design moderno, paleta de cores institucional em tons escuros e vermelho, formulário com integração direta ao WhatsApp e sistema de avaliações.

---

## 🚀 Funcionalidades

* **Apresentação Institucional:** Destaque para as principais áreas de atuação (Direito Civil, Empresarial e Trabalhista).
* **Agendamento via WhatsApp:** Formulário de triagem rápida que formata as informações do cliente e abre diretamente a conversa no WhatsApp do escritório (`+55 63 99914-4077`).
* **Seção de Avaliações / Feedbacks:** Sistema dinâmico em JavaScript utilizando `localStorage` para exibição e salvamento permanente de depoimentos de clientes no navegador.
* **Layout Responsivo & Tema Dark/Wine:** Visual elegante com tipografia clássica (Georgia/Serif) e detalhes em vermelho.

---

## 🛠️ Tecnologias Utilizadas

* **HTML5:** Estrutura semântica das seções.
* **CSS3:** Estilização com variáveis CSS (`:root`), Grid Layout, Flexbox e efeitos de transição.
* **JavaScript (ES6+):** Manipulação da DOM, integração com API do WhatsApp (`wa.me`) e persistência de dados local (`localStorage`).
